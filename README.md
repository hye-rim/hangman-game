# 행맨 🔤

숨은 한글 단어의 글자를 하나씩 골라 맞히는 행맨. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 단어의 **자모**(ㄱ, ㅏ 같은 낱글자)를 하나씩 고른다. 단어에 있으면 그 자리가 모두 열리고(초성·종성의 같은 자음 포함), 없으면 기회가 하나 줄어 행맨이 한 조각 완성된다
- 한 글자는 초성·중성·종성으로 이루어져 있어서 자모가 열리는 만큼 글자가 채워진다 (ㅅ → 사). 받침이 아직 안 열린 글자는 아래에 주황 줄이 보인다
- **보통**: 기회 7번, 분야(과일·동물·음식·나라·직업·운동·물건·자연) 힌트가 보인다 · **어려움**: 기회 5번, 분야 힌트 없음
- 쌍자음(ㄲㄸㅃㅆㅉ)과 겹모음(ㅒㅖㅘㅙㅚㅝㅞㅟㅢ)은 아래 줄 자판에 있다. 예) 사과의 '과'는 ㄱ + ㅘ 라서 ㅗ 를 고르면 틀린 것
- 💡 힌트: 단어마다 한 번, 안 열린 자모 하나를 열어 주고 기회가 하나 줄어든다 (마지막 기회일 땐 못 쓴다)
- 단어를 맞히면 점수 = 50 + 남은 기회×15 + 글자 수×10 + 연속 보너스(최대 +100). 기회를 다 쓰면 끝. 600 / 1,500 / 3,000점에 동·은·금메달
- 160개 단어(받침에 겹받침이 없는 두 글자 이상 단어). 최고 점수는 모드별 `hangmanBestNormal` · `hangmanBestHard`, 로비 표시용은 큰 값 `hangmanBest`
- PC: 한글 자판(2벌식) 그대로 입력(Shift 로 쌍자음·ㅒㅖ) · Enter/Space 다음 단어 · 숫자 1 힌트

규칙과 단어는 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력·소리는 `game.js`.
